# 🌌 VanGoVirtual

Welcome to **VanGoVirtual**, a premium virtual art gallery and live auction platform designed with a sleek, minimalist dark aesthetic. This platform allows users to browse curate collections of contemporary artwork, view detailed showcases via an immersive stay-in-place lightbox, and participate in an interactive live-bidding simulator.

## ✨ Features

*   **Premium Dark UI:** Designed using a custom midnight-purple palette, subtle grain overlay noise, and neon glow indicators.
*   **Dynamic Gallery Filtering:** Instantly sort artwork by categories (Portraits, Contemporary, Wildlife, Landscapes) without page reloads.
*   **Immersive Lightbox Stage:** View high-resolution pieces in an isolated window overlay featuring looping keyboard navigation (`ArrowLeft`, `ArrowRight`, `Esc`).
*   **Live Simulated Bidding System:** Artworks switch into active auction panels where users can place valid real-time higher bids that persist dynamically as they browse.
*   **Fully Responsive:** Designed to look completely stunning across desktop monitors, tablets, and smartphones.
